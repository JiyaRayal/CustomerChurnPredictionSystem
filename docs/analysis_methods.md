# Segment Analysis Methods (Phase 4)

Implemented in `src/churn_analytics/analysis.py`, reported by `analysis_report.py`, drawn by
`visualization.py`, and covered by `tests/test_analysis*.py`. Results: `reports/segment_churn_analysis.md`
(generated) and `reports/figures/*.png` (generated by `scripts/make_figures.py`).

## What is analysed

Nine variables are compared against churn, taken from `[analysis].segment_variables` in the config:
Geography, Gender, AgeBand, CreditScoreBand, TenureGroup, BalanceSegment, NumOfProducts, HasCrCard,
IsActiveMember. Credit score is also repeated with equal-sized terciles as a sensitivity check.
Deeper engagement, tenure, salary and balance work (for example salary vs balance) is left to Phase 5.

All results are **descriptive associations in one snapshot**. Every table is a one- or two-variable view;
age, number of products, balance, activity and country overlap, and **no table controls for the others**.
No predictive or multivariable model is built (the project brief does not ask for one).

## Measures

| Measure | Definition | Notes |
|---|---|---|
| Segment churn rate, churn contribution, customer share | as in `docs/kpi_definitions.md` | every rate has n, a 95% Wilson interval and the small-group flags |
| Rate vs overall (rate ratio) | `segment churn rate / overall churn rate` | 1.00 = average. Same idea as the Geographic Risk Index, applied to any segment. A supporting measure, not one of the brief's KPIs. Always equals `contribution / share` |
| Contribution gap (pp) | `(churn contribution - customer share) x 100` | positive = more churners than the segment's size alone suggests. Within one variable the gaps sum to 0 |
| Cramer's V | `sqrt(chi-square / (n x min(rows-1, columns-1)))` on a segment-by-churn table | 0 = no association, 1 = perfect. Chi-square without continuity correction. Because churn is binary, `min(...)` is always 1 |
| Effect-size labels | negligible / small / medium / large at V = 0.10 / 0.30 / 0.50 | Cohen's conventions, set in the config. Conventions for describing size, not tests of importance |
| p-value | from the same chi-square test | reported but not the focus: with 10,000 customers almost any difference is "significant" |
| Spread (pp) | highest minus lowest segment rate among segments with a reportable rate | small-sample segments are marked `*`, because they can inflate the spread |
| Group difference | difference of two churn rates in percentage points, **Newcombe hybrid score** interval | used for the gender gap (first configured gender minus second: Female - Male), overall and by country |
| Standardised difference d | `(mean churned - mean retained) / pooled SD`, approximate interval `d +/- z x sqrt((n1+n2)/(n1 n2) + d^2 / (2 (n1+n2)))` | labels at 0.2 / 0.5 / 0.8 (config). Undefined (n/a) when there is no variation |
| Composition | each segment's share of retained customers vs share of churned customers | the reverse view of the rate tables |

## Rules applied

* **Empty / small groups** follow the project rules: empty = n/a (never 0); below 30 customers the rate is
  withheld; below 100 it is flagged *small sample*.
* **No customer is lost:** every variable's segments add back up to all customers (tested). Missing segment
  values would get their own `(missing)` row.
* **Display labels:** 0/1 columns are shown as "No credit card / Has credit card" and "Inactive / Active"
  (config). Only the labels shown change; no value is altered.
* **Geography and zero balance:** the country x age view is shown for all customers and for non-zero-balance
  customers only, and balance segments are shown by country (design rules D24).
* **Extreme rates:** a rate of exactly 0% or 100% is listed in the report as "worth confirming with the data
  owner". The data cannot explain why; an extreme result in a small group may reflect how the data was recorded.

## Limitations

* Single-variable views can mislead when variables overlap; differences seen for one variable may partly reflect another.
* Many segments are compared, so some differences will look larger by chance, especially in small groups.
* The interval for d is approximate. Cramer's V depends on how a variable is grouped (for example AgeBand
  cut-offs); the credit-score tercile check shows how much a conclusion can depend on grouping.
* One snapshot, three countries; the meaning of `Exited` is an assumption (D6); provenance is unconfirmed.
