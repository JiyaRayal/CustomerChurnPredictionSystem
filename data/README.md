# data/

| Folder | Purpose | Rules |
|---|---|---|
| `raw/` | Original dataset exactly as received | **Never edit.** File is read-only; `SHA256SUMS` records its fingerprint. |
| `processed/` | Cleaned data and derived segment columns (created in Phase 2) | Always regenerated by code from `raw/`; never edited by hand. |

## Raw file

`raw/European_Bank.csv` - 10,000 rows x 14 columns (see `docs/data_provenance.md`).

SHA-256: `31be60acb8660d5a343b85debd4ad444953305d855834ea0dd09f11c659002a2`

Verify on Linux/macOS: `cd data/raw && sha256sum -c SHA256SUMS`

## Git and the raw CSV

By default `.gitignore` excludes the CSV (the original source and redistribution
terms are unconfirmed, and the file contains customer surnames). If you clone the
repository, copy `European_Bank.csv` into `data/raw/` yourself and verify the checksum.
